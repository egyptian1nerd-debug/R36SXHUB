Automatic downloads (one-time setup, free)

GitHub does not let web pages download its release files, so the page needs a tiny relay that you own. It takes about 3 minutes and you only do it once:

  1. Make a free account at dash.cloudflare.com, then open Workers & Pages and create a new Worker (the button names may differ a little).
  2. Open the code editor, delete everything in it, paste the code below, and press Deploy.
  3. Copy the address it gives you (it ends in .workers.dev) and paste it here.
// R36SX Hub relay: lets the hub page download GitHub release files.
// It only forwards release downloads from the repos listed below.
const ALLOWED = /^https:\/\/github\.com\/tzubertowski\/(TreeFrogUI|TreeFrogUI-installer|H\.OS_stock_backup|mini-scraper-cfw)\/releases\/download\//;
const CORS = {
  "access-control-allow-origin": "*",
  "access-control-allow-methods": "GET, HEAD, OPTIONS",
  "access-control-allow-headers": "range",
  "access-control-expose-headers": "content-length, content-range"
};
export default {
  async fetch(request) {
    if (request.method === "OPTIONS") return new Response(null, { headers: CORS });
    const target = new URL(request.url).searchParams.get("url") || "";
    if (!ALLOWED.test(target)) return new Response("Not allowed", { status: 403, headers: CORS });
    const range = request.headers.get("range");
    const upstream = await fetch(target, { redirect: "follow", headers: range ? { range } : {} });
    const headers = new Headers(upstream.headers);
    for (const k in CORS) headers.set(k, CORS[k]);
    return new Response(upstream.body, { status: upstream.status, headers });
  }
};

Artwork scraper

Mini Scraper adds box art to your ROMs for TreeFrogUI and other handheld frontends. It runs on your PC and reads and writes the SD card directly.

Download Mini Scraper

Checking the latest version...

  1. Unzip it and run Mini Scraper.
  2. Keep the artwork source on Automatic (no account needed).
  3. Choose your SD card, confirm it detected TreeFrogUI, then press Add artwork.
